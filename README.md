# Kavinkumar G — Enhanced Portfolio

## What's included
- Modern dark/glassmorphism developer portfolio
- JavaScript typing animation
- Scroll reveal animations
- Active navigation highlighting
- Responsive mobile navigation
- Cursor glow effect
- Your uploaded profile photo
- Experience, skills, projects, education, certifications and achievements
- Resume download button
- LinkedIn, email and phone contact links

## Run
Open `index.html` in Chrome/Edge.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `kavinkumar-portfolio`.
2. Upload all files and folders from this ZIP.
3. Go to Settings → Pages.
4. Select the `main` branch and root folder, then save.
5. GitHub will generate your live portfolio URL.

## Before applying
Replace/add your GitHub profile URL when you have one. Project GitHub/live-demo buttons can also be added later.
